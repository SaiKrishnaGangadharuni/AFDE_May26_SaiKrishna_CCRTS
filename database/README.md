# CCRTS Database

This folder contains the canonical database schema and seed data scripts.

## Files

- **`schema.sql`** — DDL for all 7 tables (Roles, Users, Categories, Complaints, ComplaintHistory, Attachments, Feedback, Notifications) plus all indexes and constraints.
- **`sample-data.sql`** — Roles and Categories sample inserts.
- **`er-diagram.md`** — Entity-Relationship diagram (Mermaid).

## Tech

Default: **SQLite 3** — file-based, zero-setup. The runtime DB lives at `backend/ccrts.db` after first launch.

## Quick Start

The easiest path is the Python seed which inserts everything correctly:

```bash
cd backend
python seed.py
```

If you prefer raw SQL:

```bash
sqlite3 backend/ccrts.db < database/schema.sql
sqlite3 backend/ccrts.db < database/sample-data.sql
# Users still need to be inserted with bcrypt-hashed passwords - use seed.py
```

## Switching to PostgreSQL

1. Install PostgreSQL and create a database: `createdb ccrts`
2. Set `DATABASE_URL=postgresql://user:pass@localhost:5432/ccrts` in `backend/.env`
3. Install the driver: `pip install psycopg2-binary`
4. Run the schema (works with minor edits — replace `AUTOINCREMENT` with `GENERATED BY DEFAULT AS IDENTITY`, change `BOOLEAN DEFAULT 1` to `BOOLEAN DEFAULT TRUE`).
5. Run `python backend/seed.py` — SQLAlchemy handles the rest.
